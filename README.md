# App99 Rides Data Analysis

Projeto de Análise de Dados utilizando dados reais de corridas realizadas como motorista parceiro da plataforma 99.

## 📖 Sobre o Projeto

Este projeto foi desenvolvido com o objetivo de praticar todo o processo de Análise de Dados utilizando um conjunto de dados real, coletado durante minhas corridas como motorista parceiro do aplicativo 99.

Durante o desenvolvimento serão aplicadas técnicas de auditoria, tratamento, exploração e visualização dos dados utilizando Excel, SQL, Python (Pandas) e Power BI.

Além do aprendizado técnico, o projeto busca responder perguntas de negócio que possam contribuir para uma melhor tomada de decisão e otimização do faturamento das corridas.

---

## 🎯 Objetivos

Responder perguntas como:

- Qual o faturamento total do período analisado?
- Qual o ticket médio das corridas?
- Qual cidade gera maior faturamento?
- Qual cidade possui o maior ticket médio?
- Qual tipo de pagamento é mais utilizado?
- Qual horário apresenta maior potencial de faturamento?
- Existem padrões que possam contribuir para aumentar o rendimento das corridas?

## 📊 Dataset

O dataset utilizado neste projeto foi construído manualmente a partir do histórico de corridas realizadas no aplicativo 99.

Atualmente contém:

- 99 corridas
- Dados do mês de março de 2026
- Corridas realizadas no modelo híbrido (CLT + Aplicativo)

As principais variáveis analisadas são:

- Data
- Hora
- Valor
- Tipo de pagamento
- Cidade de origem
- Cidade de destino
